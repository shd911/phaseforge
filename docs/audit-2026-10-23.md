# Аудит 2026-10-23 (b141.100)

Полный аудит: математика DSP, надёжность Rust, логика фронтенда, отображение графиков,
построение интерфейса. Две независимые части:

- **Свой аудит** — 5 субагентов, по одному на область. Каждая находка подтверждена временным
  тестом (cargo / vitest), замером на реальных фикстурах (`test-fixtures/prering/`) или
  трассировкой кода. Временные файлы удалены.
- **Внешний аудит** — 6 пакетов кода (P1 FIR, P2 target+PEQ, P3 Rust прочее, P4 логика
  фронтенда, P5 графики, P6 оболочка UI) разосланы через OpenRouter моделям MiniMax M3.1
  flash, NVIDIA Nemotron 3 Ultra, Poolside Laguna S 2.1, Cohere North mini code, Gemma 4 31B.
  Каждое утверждение моделей проверено по коду репозитория отдельным агентом; ниже только
  подтверждённое, отдельно — сводка ложных.

Итого: **75 своих + 38 новых от внешних моделей = 113 находок**. Исправлений не делалось.

Метки: `[ext: модели]` — находка внешнего аудита (проверена), без метки — свой аудит.

## 1. Математика DSP

1. **HIGH** PEQ или целевая полка выше Найквиста экспорта на IIR-пути: полюса за единичным
   кругом (радиус 1,047–1,299), импульс Inf/NaN, norm_db −400, Export рисует ровные 0 дБ
   (`iir_path.rs` 262, 186). = 2.1.
2. **MED** Шумовой хвост −150 дБ от 0,95·Nyq до Nyq (`band.rs` 217-228) на кепстральном
   min-пути даёт лишнее фазовое отставание: HP LR4 2k, 44,1k: −7° @2k, −42° @10k, −89,5° @15k
   против IIR; на графике его нет. Сумма твитер (кепстр) + вуфер (IIR): −0,32 дБ на 8 кГц.
3. **MED** Tilt в FIR на min-main минимально-фазовый (−14,4° @1k при −1 дБ/окт), а в модели
   графика/Σ — нулевой фазы; на lin/mixed — нулевой. Невидимые ~15° на кроссовере, если tilt
   не на всех полосах.
4. **MED** ФНЧ кроссовера ≥ Nyq экспорта: на IIR-пути экспорт падает «fc out of range», на
   кепстральном молча пропускается (`iir_path.rs` 190, `helpers.rs` 52).
5. **LOW** Целевые полки: аналоговая модель (график, кепстр) против цифровой RBJ (IIR-путь):
   HS 10 кГц −6 дБ при 44,1k: −0,72 дБ / +6,9° @15k, +12,9° @20k. `[ext: laguna, nemotron — дубль]`
6. **LOW** Настройки narrowband_limit / nb_* читаются только в legacy-пути — в UI есть
   настройки, которые ничего не делают.
7. **MED** `[ext: minimax]` Лимит звона `max_ring_ms` не гарантирован, Q уходит ниже Q_MIN 0.5
   и ниже минимума поля Q в UI (0.1): `q_envelope.rs` 74-96 при отсутствии подходящего Q
   возвращает Q с минимальным звоном без снижения усиления; `lma.rs` 246-248 и финальная
   защита `peq/mod.rs` 317-324 опускают Q после clamp. sub_10x4, гибрид, 176,4k/128K, авто
   20–1299 Гц: 20 Гц **+48,9 дБ Q 0,099, звон 447 мс** при лимите 371,5; стандарт 48k/4096:
   20 Гц +6 дБ Q 0,355 — 90 мс при 42,7. `tests/peq_ring_limit.rs` не ловит (диапазон от 24 Гц,
   продакшн-автодиапазон — от 20).
8. **MED-LOW** `[ext: minimax]` «Уровень» цели (−20…+20 дБ) входит в FIR-запрос, поэтому
   «Макс. подъём» и порог шума работают по абсолютному уровню, а не относительно цели
   (`evaluate.ts` 310/460 → `target/mod.rs` 167 → `band.rs` 211; `cepstral.rs` 124-129, 153;
   `band.rs` 239). «Corrected» строится без уровня. 48k/64K, LR4 80/3k, PEQ +6 @200 Гц:
   лимит 24, уровень 0/+10/+20 → реализованный подъём 5,73/5,73/3,73 дБ; лимит 6, уровень +3 →
   2,73 дБ (PEQ срезан вдвое); IIR, уровень +20 → ложное «подъём 26,0 дБ выше лимита»;
   порог −60, уровень −20 → полоса задерживания −40 вместо −60.
9. **LOW-MED** `[ext: minimax]` `max_error_db` считается до финальной защиты: в тосте
   «макс. ошибка» 16,17 дБ при фактических 8,23 у возвращённых фильтров (`peq/mod.rs`
   302-304 vs 317-324; `polish_bands` 383-390 поднимает Q обратно до 0,5).
10. **LOW-MED** `[ext: minimax, nemotron]` Продвижение в полку обходит «Подъём до»
    (`lma.rs` 570-592; `max_boost_at` проверяет только центр): mid90, LR4 300/3000, гибрид →

## 2. Надёжность Rust

1. **HIGH** PEQ/high-shelf выше Найквиста экспорта на IIR-пути → FIR из NaN (`iir_path.rs`
   262-276, 372-377): 48k, PEQ 24,5 кГц → 8488 NaN из 65536; 26–29 кГц → 26–31 тыс. NaN.
   Экспорт WAV падает «invalid type: null». Сценарий: PEQ подобран на 96k, экспорт
   переключён на 48k, или ручной PEQ 25 кГц.
2. **MED** `fir_noise_floor_db > fir_max_boost_db` → паника `f64::clamp` (`cepstral.rs` 124,
   `helpers.rs` 593), IPC висит; `validate_project` не проверяет.
3. **MED** Снапшот подменяет файл NF/FF другой полосы при совпадении имён (`snapshots.rs`
   208-217): версия восстанавливается с чужим замером без ошибки.
4. **MED** Одновременные save_project в один путь: фиксированное имя `.tmp` → ложная ошибка
   записи; параллельный create_snapshot теряет записи индекса.
5. **MED** Импорт отвергает файл целиком: UTF-8 BOM, Latin-1/UTF-16, заголовок без «*»,
   «;»-комментарии, CSV (`parser.rs` 16, 66, 76) — типично для ARTA/VituixCAD/Excel .frd.
6. **LOW-MED** Несогласованные длины массивов в IPC-командах → паника (`phase/mod.rs` 54,
   375; `impulse.rs` 28; `smoothing.rs` 62). Защита от будущих багов.
7. **LOW** create_snapshot оставляет пустой .pfproj и папку при сбое копирования.
8. **LOW** export_fir_wav не проверяет NaN/Inf, sr=0, пустой импульс; запись не атомарна.
9. **LOW** Парсер принимает отрицательные частоты и абсурдные уровни.
10. **LOW** Слияние NF+FF берёт пересечение диапазонов — НЧ ближнего поля ниже начала FF
    выбрасываются без предупреждения (`merge.rs` 69-70, 121-128).
11. **LOW** evaluate_target_standalone с f_max=0 → NaN-сетка; n_points без предела.
12. **LOW** analyze_measurement синхронная (34 мс на 1 млн точек).
13. **LOW** recent.rs пишет не атомарно, битый JSON молча обнуляет список; журнал растёт без
    предела.
14. **MED** `[ext: minimax, nemotron]` Фикс b141.56 оценки задержки замера в продакшне не
    работает: `sample_rate` всегда None (`parser.rs` 150, `merge.rs` 220; фронт передаёт
    null — `measurement-actions.ts` 39/86, `FrequencyPlot.tsx` 4042, `project-io.ts` 526 →

    отбраковки отрицательной задержки; минимальная фаза строится с Найквистом = последняя
    точка сетки. Журнал: ни одной записи «LS fit rejected», ~15 вызовов → 0,0000 мс.
    Синтетика: твитер BW2 2k +0,08 мс → 0 (−288° на 10 кГц, = M6 аудита 2026-10-01).
    Фикстуры: 8x-NF −0,356 мс, 6.5M-NF −0,140 мс — отрицательное время пролёта применяется.
    Тест b141.56 проверяет только `Some(48000)`.
15. **LOW, скрытая** `[ext: minimax]` `compute_ir_delay` держит АЧХ и фазу плоскими выше сетки
    (`phase/mod.rs` 351-361): 2 мс при 48k → 2,000, при 96k → 0,000. Всплывёт при починке 2.14.
16. **LOW** `[ext: minimax, nemotron]` Слияние NF+FF: отбракованная подгонка FF (0) берётся

Выводы:
- **MiniMax** — единственная полезная модель: треть утверждений подтверждается, нашла реальные
  дефекты в project-io, оптимизаторе, графиках. Но отвечает рассуждением (130–180 тыс. знаков),
  из которого находки приходится извлекать вручную; одну верную (уровень цели) сама отклонила.
- **Nemotron** — ~10 % попаданий, лучше всего на UI (P6: 5 находок, включая Gaussian в окне
  кроссовера).
- **Laguna** — быстрая, оформленная, почти полностью ложная (шаблонные «утечки», «двойной
  PEQ», «нет unwrap»).
- **Cohere** — во всех пакетах уходит в бесконечный повтор, непригодна.

Повторяющиеся ложные находки (не перепроверять):
- фаза/нормировка HP у BW/Bessel/LR/Custom — сверено с аналитикой до 0,01 дБ/0,01°;
- Gaussian HP = 1−LP «даёт −3 дБ», «фаза Gaussian = 0» — конвенция, Гильберт отдельно;
- сумма dB = каскад; коэффициент звона c = |A²−1| верен;
- «PEQ применяется дважды» в assemble_complex_spectrum / peq_eff — refined стартует с полной АЧХ;
- «интерполяция фазы без unwrap» — фаза развёрнута до интерполяции (cepstral.rs, iir_path.rs);
- «ГВЗ от обёрнутой фазы», «двойной null на ±180°» — разрыв одобрен;
- «утечки обработчиков» в FrequencyPlot/диалогах — компоненты не размонтируются, ссылки те же;
- `refLevelOverride` в ключе суммы — SumEvalOptions его не имеет (параметр мёртвый, не баг);
- «buildFirGrid нарушает единую Гильбертову сетку» — FIR и Гильберт считает Rust на своей сетке;
- NaN/Inf в unwrap/ГВЗ/детекторах — отсекает парсер и validate_project.
